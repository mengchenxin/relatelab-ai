RelateLab 隐私与数据说明

版本：2026-09-22

我们处理什么数据

  • 用户上传的聊天截图
  • 用户选择的关系类型和分析目标
  • 系统生成的脱敏文本、时间线、安全判断、策略和运行记录

截图如何处理

聊天截图会发送给用户配置的 DeepSeek 视觉模型，用于读取消息内容并完成分析。 默认不把原始截图写入案例库。

API Key 如何处理

API Key 仅保存在当前浏览器标签页的 sessionStorage， 分析时通过请求头临时发送给后端。系统不会把 Key 写入数据库、Trace、案例库或应用日志。 关闭标签页或浏览器后，Key 会自动清除。

数据保留

案例分析默认保留 30 天，超期记录会自动清理。具体保留期限以线上健康接口返回的配置为准。

用户权利

  • 用户可以删除单个案例
  • 用户可以在“系统状态”页面删除自己的全部数据
  • 不同匿名会话的案例相互隔离，不能互相读取或删除

安全边界

RelateLab 用于沟通分析和决策支持，不提供心理诊断、医疗建议或紧急救援。 如果存在自伤、暴力或人身危险，请优先联系当地紧急服务和可信赖的现实联系人。

问题与删除请求

可以通过 GitHub 仓库提交问题： github.com/mengchenxin/relatelab-ai/issues
