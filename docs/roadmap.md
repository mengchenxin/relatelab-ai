# Roadmap

## Phase 1: Vertical slice

- Structured case contract
- Text and screenshot intake
- Redaction
- Timeline extraction
- Dynamics analysis
- Safety triage
- Strategy generation
- Trace and run persistence

## Phase 2: Retrieval and model quality

- Versioned prompt registry
- Retrieval over communication frameworks and anonymized cases
- Model comparison runs
- Human review queue
- Regression dataset with disagreement tracking

## Phase 3: Production platform

- PostgreSQL and pgvector
- Redis workers
- OpenTelemetry and Langfuse exporters
- Authentication and tenant isolation
- Encrypted object storage
- Retention and deletion workflows

## Phase 4: Product research

- Measure strategy adoption and user-reported outcomes
- Track false safety positives and missed safety signals
- Add calibrated uncertainty and evidence-linked conclusions
- Evaluate whether recommendations improve relationship outcomes over time
